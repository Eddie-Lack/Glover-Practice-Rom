# Frame advance

_Back to the [Home page](Home.md)_

| Option | What it does |
| --- | --- |
| Frame advance | Pause the game, or let it run again. Quick action |
| Frame step | While the game is stopped, run one game frame. Quick action |
| Slow motion | Run the game at 1/2, 1/3 or 1/4 speed, or off. The quick action "Slow motion" steps through the four choices |

The default bindings are on the [Controls](Controls.md) page

Hold the Frame step binding to step again and again: after a short wait it runs a game frame on every second controller read

The default Frame step binding uses the stick, and the game doesn't see the stick until you let it go. To hold the stick or a button for the stepped frame, bind Frame step to controller 2 _(see [Bindings](Bindings.md))_

Turned on during a fade or a level's load, frame advance lets the load run and stops on the level's first game frame

A save or a load while the game is stopped happens at once, on the frame you see

Frame advance and slow motion stop input recording and playback. A run that used frame advance or slow motion does not count for a practice best time. The free camera also flies while the game is stopped _(see [Game](Game.md))_
