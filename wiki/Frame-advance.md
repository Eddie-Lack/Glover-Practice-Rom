# Frame advance

_Back to the [Home page](Home.md)_

| Option | What it does |
| --- | --- |
| Frame advance | Pause the game, or let it run again. Quick action |
| Frame step | While the game is stopped, run one game frame. Quick action |
| Slow motion | Run the game at 1/2, 1/3 or 1/4 speed, or off. The quick action "Slow motion" steps through the four choices. |

The default bindings are on the [Controls](Controls.md) page

Frame advance and slow motion stop input recording and playback. A run that used frame advance or slow motion does not count for a practice best time. The free camera also flies while the game is stopped _(see [Game](Game.md))_
