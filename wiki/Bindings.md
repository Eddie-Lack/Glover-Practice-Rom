# Bindings

_Back to the [Home page](Home.md)_

Bindings are the button combinations that start quick actions. The menu has one item for each of these actions: Reset level, Warp, Last checkpoint, Go to checkpoint, Frame advance, Frame step, Slow motion, Hide HUD, Save state, Load state, Record input and Play recording

The default bindings are on the [Controls](Controls.md) page

## Change a binding

1. Select the action and press A
2. Let go of every button
3. Press the buttons you want, then let go of them all.

Combinations made on controller 1 include the stick direction that you hold, if any. If you don't press anything for a few seconds, the change is cancelled

Press L on an action to clear its binding

Bindings trigger when their buttons are held and the last one has just been pressed. On controller 1, the bound buttons are hidden from the game while the binding triggers
