## The menu

Press all four C buttons on controller 1 to open and close the practice menu

| Button | In the menu |
| --- | --- |
| D-pad up and down | Move to the previous or next item. Hold to repeat |
| D-pad left and right | Change a value. Hold Z to change in steps of 10 |
| A | Choose the option |
| B | Go back one menu - In the top menu, close the menu |
| L | On a binding in the [Bindings](Bindings.md) menu: clear it |

You can set the menu's opacity and its position on the screen in the Settings menu

By default the game pauses while the menu is open. The Settings menu has a toggle, "Pause game in this menu", to set this. _See [Settings](Settings.md)_

Some items show a warning when you select them (for example, "Modified game! May crash")

## Quick actions

Hotkeys for menu actions that you can activate while playing. Hold the analog stick fully in a direction, then press a D-pad direction. These are the defaults:

| Stick | D-pad up | D-pad right | D-pad down | D-pad left |
| --- | --- | --- | --- | --- |
| up | reset the level | last checkpoint | warp | hide the HUD |
| down | frame advance on or off | one game frame | none | slow motion |
| left | save state | play the recording | load state | record input (again: stop) |

You can change each one in the [Bindings](Bindings.md) menu

The quick actions are:

- Reset level, Warp, Last checkpoint: _see [Warp](Warp.md)_
- Save state, Load state, Record input, Play recording: _see [Savestate](Savestate.md)_
- Frame advance, Frame step, Slow motion: _see [Frame advance](Frame-advance.md)_
- Hide HUD: _see [HUD](HUD.md)_

## Controller 2

A controller in port 2 can have its own bindings. Bindings on controller 2 don't need a stick direction. Bind it in the [Bindings](Bindings.md) menu by pressing the buttons on controller 2

Controller 2 has more uses:

- With "Controller 2: debug controls" on, use game's hidden debug controls _(see [Game](Game.md))_
- With moon jump on, you can also activate it with L on controller 2 _(see [Game](Game.md))_
- With the free camera on, it flies the camera _(see [Game](Game.md))_

You can only open the practice menu with controller 1.
